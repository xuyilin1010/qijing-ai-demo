# 贵烟（细支行者）SVG 交互公众号推文设计稿

> 复刻对象：迪桑特「寻找同频的人一起破风」SVG 交互推文
> 品牌调性：深蓝宇宙 / 金色光芒 / 行者精神 / 冰咖啡爆珠
> 技术方案：竖屏长图 + SVG 交互 + 公众号原生组件（视频号/小程序/二维码）

---

## 一、整体结构

| 顺序 | 模块 | 交互 | 参考页 | 视觉风格 |
|------|------|------|--------|---------|
| 1 | 竖屏封面 | 上下箭头呼吸动效 | P2 / P3 | 宇宙漩涡 / 孤勇者 |
| 2 | 产品介绍 3 页 | 下滑查看 | P3 / P6 / P7 | 文化核心 → 产品定位 → 参数卡 |

| 4 | 消费群体画像 | 下滑查看更多 / 吸附滚动 | P15-P18 | 三大先锋圈层 |
| 5 | 品牌价值 | 图文依次展示 | P19-P23 | 关键词 + 梦想/探索/自由 |

## 二、尺寸规范

- 基础画布宽度：**750px**（iPhone 标准）
- 竖屏封面：750 × 1624 px（9:19.5，全屏）
- 内容页：750 × 1334 px（9:16）或 750 × 1500 px
- 横版长图段：可复用 PDF 1600×900 横向构图，在公众号内以 750 × 1334 容器展示并提示横屏
- 字体：建议导出为图片或转曲；如用公众号文字，使用系统黑体

### 模块 3：三感切换（核心交互）

复刻迪桑特的「三人点选」结构，改为「观感 / 口感 / 情感」三个圆形入口。

**布局**：
- 背景：深蓝 + 金色光流（可复用 P15/P16 背景粒子效果）
- 顶部标题：`一度三感  味觉新境`
- 三个圆形按钮横向排列：
  - 观感：眼睛图标 / 或「观」字
  - 口感：嘴唇/水滴图标 / 或「味」字
  - 情感：心形图标 / 或「感」字

**文案**：

观感（默认显示）：
```
观感
先锋设计

承袭行者经典黄黑配色
植绒视窗 · 日照金山
每一次注目，都是不凡
```

口感：
```
口感
冰咖爆珠

3.5mm 大径爆珠
薄荷精粹与咖啡醇厚交织
一捏即享冰爽醇香
```

情感：
```
情感
行者共鸣

行者之名，焕新再启
追逐梦想、敢于探索、向往自由
```

**SVG 交互逻辑**：
- 三个圆形按钮均可点击；
- 点击后当前按钮高亮（金色描边 + 发光）；
- 下方内容卡片通过 `<set>` 切换 `display` 属性；
- 背景图可随三感微微切换（如观感放 P9/P10/P11 包装，口感放 P12/P13 爆珠，情感放 P14/P21）。

| 屏 | 背景图 | 文案/交互 |

| 6 | 星空下张开双臂 | 情感金句：真正的行者，不追问终点 |
| 7 | 三职业分镜 | **消费画像**：户外探索者 / 品质创新者 / 潮流先锋者（点切换） |

| 9 | 抽象光流地平线 | 结尾 CTA：下一站，行者同行 |

### 横屏实现要点

1. **整体大图**：将 9 张 1536×1024 精修图压缩后横向拼接成 10368×768 的 JPG，作为连续背景；
2. **公众号落地**：微信内不支持超大单图全屏横滚，建议把大图切成 3-5 段 750 宽的长图，或在 SVG 里用 `<image>` 分块拼接；
3. **吸附分节**：HTML 原型使用 `scroll-snap-type: x mandatory` + 9 个等宽面板；公众号内可用 E2.COOL「等分容器横向滑动」模板；
4. **三感切换**：在横屏第 5 屏使用 `xingzhe_sense_switch_horizontal.svg`，通过 `onclick` 修改 opacity/visibility；
5. **消费画像**：在第 7 屏用 3 个圆点切换 3 段文案，结构与三感切换一致；
6. **旋转提示**：用户竖屏打开时先展示 `xingzhe_rotate_hint.svg`，提示横屏后进入正文。

## 五、交互实现说明

1. **上下箭头呼吸**：SVG `<animateTransform>` + `<animate opacity>`；
2. **三感切换**：SMIL `<set begin="btnX.click">` 切换 `display`；
3. **画像吸附滚动**：CSS `scroll-snap-type: y mandatory` + 公众号长图分段；
4. **路径/光流动画**：SVG `<path>` + `stroke-dashoffset` 动画，或简单 `<animate>`；
5. **跳转**：使用公众号原生 `<mp-common-videosnap>`、小程序卡片、`<a>` 链接。
