## 二、从原型到公众号落地的步骤

### 步骤 1：准备最终图片素材

原型中使用的 `pdf_pages/hi_p*.jpg` 是设计稿截图，**不能直接用于公众号发布**。请让设计提供：

- 竖版 9:16 或 2:3 的封面图（750×1334 或 1080×1785 px）
- 产品介绍 3 页竖版图
- 三感切换背景图（共 3 张）
- 三大消费群体画像竖版图（共 3 张）
- 品牌价值页竖版图（共 4 张）
- 结尾 CTA 背景图

上传至公众号素材库，获取以 `mmbiz.qpic.cn` / `mmecoa.qpic.cn` 开头的图片 URL。

### 步骤 2：替换 SVG 中的图片地址

打开 `xingzhe_sense_switch.svg`，把以下占位地址替换为真实素材 URL：

```svg
<image href="https://your-cdn.com/hi_p09.jpg" ... />
<image href="https://your-cdn.com/hi_p12.jpg" ... />
<image href="https://your-cdn.com/hi_p14.jpg" ... />
```

### 步骤 3：粘贴 SVG 到公众号编辑器

1. 打开微信公众号后台 → 新建图文消息；
2. 使用支持 SVG 的编辑器（如 E2.COOL）插入「SVG 代码」组件；
3. 把 `xingzhe_sense_switch.svg` 完整代码粘贴进去；
4. 确保外层包裹的 `section` 设置 `line-height: 0; font-size: 0;`；
5. 预览真机效果，检查点击区域是否灵敏。

### 步骤 4：接入公众号原生组件

- **视频号**：使用 `<mp-common-videosnap>` 组件，替换 `data-url`、`data-id` 等参数；
- **小程序**：使用公众号小程序卡片或 E2.COOL「无图标小程序」模板；
- **超链接**：使用 E2.COOL「无图标超链接」模板生成可点击热区。

## 三、横屏全景版本落地要点

### 1. 大图处理

- 原型使用 `xingzhe_panorama_bg.jpg`（10368×768，约 1.6MB）；
- 公众号单图上传限制 10MB，但微信对超大图会压缩，建议切成 **3 段 3456×768** 或 **4 段 2592×768**；
- 切图后按顺序排版，用 `<section>` 横向连续展示，或借助 E2.COOL「等分容器横向滑动」模板。

### 2. 旋转提示

- 在文章顶部插入 `xingzhe_rotate_hint.svg`；
- 更稳妥的做法是做成首屏：竖屏显示旋转提示 SVG，用户旋转手机后微信浏览器自动重排。

### 3. 横屏三感切换

- 使用 `xingzhe_sense_switch_horizontal.svg`；
- 把它放在第 5 屏位置；点击「观感 / 口感 / 情感」切换内容卡片；
- 替换 `taste_capsule.jpg` 为真实产品图。

### 4. 消费画像切换

- 参考 `xingzhe_horizontal_article.html` 第 7 屏逻辑；
- 在公众号内可用同一套 SVG 模板：3 个圆点 + 3 段文案，通过 `<set>` 切换 `display`。

### 5. 拖拽与吸附

- HTML 原型使用 CSS `scroll-snap-type: x mandatory`；
- 公众号内若无法保证容器宽度，可改用 E2.COOL 横向滑动模板，或把交互降级为「左滑查看更多」分屏图。

## 四、公众号兼容性注意事项

1. **不依赖外部 JS**：公众号环境会过滤或限制外部脚本，所有交互必须基于 SVG SMIL / CSS；
2. **图片尺寸**：单张图片建议不超过 2MB，长图宽度以 750px 或 1080px 为基准；
3. **SVG 动画**：iOS 微信支持较好，安卓部分机型可能出现 SMIL 动画卡顿，建议真机实测；
4. **scroll-snap**：原型中的吸附滚动在公众号内可能受限于外层容器，可考虑改为 E2.COOL「等分容器吸附滑动」模板；
5. **字体**：公众号不支持自定义字体，标题文字建议导出为图片，或只使用系统黑体。

---

## 四、文案合规提示

- 避免「第一」「最好」「最佳」等绝对化用语（设计稿中已有「第一包」等表述，发布前建议法务确认）；
- 烟草产品在大众传播媒介的广告受《广告法》限制，建议以「品牌文化」「企业形象」角度发布；
- 图片中避免出现未成年人、鼓励吸烟场景，保留「吸烟有害健康」提示。

## 五、需要客户/设计补充的内容

1. 确认「花名：山咖咖 / 冰小咖 / 冰行者」是否对外使用；
2. 提供三感切换的真实产品图（观感/口感/情感各 1 张）；
3. 提供三大消费群体画像的真实人物场景图；
4. 确认 CTA 跳转目标（官网、视频号、小程序、活动页）；
5. 是否需要「旋转屏幕」横屏体验？若需要，需提供横版长图素材。
