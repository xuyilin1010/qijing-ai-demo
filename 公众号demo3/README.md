## 内容结构

**1. 封面** → 味觉拓疆者 / 行者精神

**2. 产品介绍（3 页）** → 文化核心 → 产品定位 → 产品名片

**3. 三感切换（核心交互）** → 观感 / 口感 / 情感，点击切换

**4. 消费群体画像（3 组）** → 户外探索者 / 品质创新者 / 潮流先锋者

**5. 品牌价值** → 追逐梦想 · 敢于探索 · 向往自由

**6. 结尾 CTA** → 视频号 / 小程序 / 二维码（待接入真实链接）

## 技术说明

- 横屏版使用 CSS `scroll-snap-type: x mandatory` 横向吸附，`#track` 宽 900%、`object-fit: cover` 让每屏刚好铺满手机宽度；
- 竖屏版为长图顺读 + CSS 动画；
- 三感切换与消费画像切换均为纯 SVG / CSS 实现，**不依赖外部 JS**，以适配公众号环境；
- 所有背景图已去水印并压缩（全景底图约 1.6MB）。

## 合规提示

- 烟草内容在大众传播媒介受《广告法》限制，建议以「品牌文化 / 企业形象」角度发布；
