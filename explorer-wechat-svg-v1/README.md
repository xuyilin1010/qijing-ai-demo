# 向未知前行｜横幅长卷独立迭代版

本目录的预览以 `explorer-long-scroll-demo` 为基准。封面保持竖版；点击封面后展开原有横幅长卷。方向、背景构图、章节、文案、人物故事与交互代码均与原版相同，原版目录没有修改。

预览入口：`index.html`。运行只引用 `assets/*.webp`，保留原版已压缩图片。

这仍是网页版交互预览。原版使用 Canvas 与 JavaScript 完成横向滚动、手机竖屏旋转映射、Tab 和人物故事切换，因此不能直接当作已在公众号后台验证的无脚本 SVG 正文。要做迪桑特式公众号原生版，需要在保持本版构图和方向的前提下重建交互，并在目标公众号草稿保存及手机预览中验证。
