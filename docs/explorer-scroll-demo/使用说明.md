# 向未知前行 · 第二版

更新日期：2026-09-20。基于前一版蓝金横幅，增加竖屏入口与完整七章内容。本版是本地 H5 交互样稿；产品、视频、联系方式和正式文案尚待补充。

## 打开

- 双击 index.html：完整交互。也可打开本机预览 http://127.0.0.1:4763/v2/index.html 。
- 长卷总览.html：按顺序展示七章和全部切换状态，共 11 个横屏画面。
- 尺寸预览.html：切换手机横屏、竖屏沉浸、竖屏适配的尺寸模拟。

预览服务只监听本机；127.0.0.1 链接不能直接给另一台手机访问。HTML 文件及本地素材可以离线打开。此次没有发布到任何托管站点。

## 操作

1. 竖屏封面先选择“横屏沉浸”或“适应屏幕”，轻触“开启长卷”。封面收起后显示正文。
2. 横屏沉浸模式在竖屏设备上旋转正文；设备本身转为横屏后自动恢复正常方向。适应屏幕模式保持当前方向并重新排版。
3. 左右滑动、底部章节按钮、左右箭头或键盘左右键，切换七个章节。
4. 场景视频章内，点“星空 / 攀岩 / 奔跑”切换背景、标题、文案及对应 16:9 视频占位。占位没有视频封面、假播放按钮或播放行为。
5. 人物画像的三个入口直接进入对应人物故事。故事页上下滑动、鼠标上下拖动、滚轮、上下箭头按钮和键盘上下键均可切换，图片和文字同步更新。在故事首尾继续沿边界方向滑动，可回到前一章或进入联系页。
6. 右上角“返回封面”或联系页“回到起点，再看一次”重置阅读入口。重新进入从文化章开始，场景和故事也重置为第一项。
7. “暂停动效”可暂停悬浮等动画；系统减少动态设置也会被遵循。

## 素材替换

- 两页产品图是独立于背景的贴图。分别替换 index.html 中两处 product-cutout 的 src；推荐透明 PNG，保留透明背景，不必把产品合成进大背景。
- 三个视频区域为 .video-slot，按实际视频素材或目标平台的视频组件接入。此次未生成视频封面。
- 联系页二维码是明确标注的版式占位，不可扫描；正式二维码、账号名称、邮箱、电话到位后再替换，没有编造真实联系方式。
- 产品介绍只保留通用排版文案，没有虚构规格、成分或功效。正式内容在 index.html 中编辑。

## 适用环境与验证边界

本版横卷、手势状态、布局旋转与视频占位使用 HTML/CSS/JavaScript；图标和产品占位使用 SVG。本版不是可直接粘贴进公众号的无脚本 SVG 正文。
本地浏览器已检查主要按钮、重置、场景切换、人物滚动/拖动及模拟横竖屏。手机微信真机、公众号编辑器保存过滤及发布均未验证。
