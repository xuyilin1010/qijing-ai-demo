# 公众号 SVG 交互案例库 · 灵感漫游指南

手机优先的连续长卷演示。背景是一张原创 **900 × 36700 的 SVG 长图**，32 个体验站沿着同一条小镇道路展开。底部「漫游地图」可以直接跳转，也可以按顺序向下阅读。没有第三方前端依赖，无需构建即可部署。

## 手机预览

## 公众号与网页的边界

这是网页形式的交互案例库，**不是能整体粘贴进公众号编辑器的成品代码**。10 站原生 SVG 的动效由 SMIL 实现，其余包含 H5、Canvas、手势与媒体编排，目录中已分别标注。具体公众号项目需要按发布平台适配，并在微信草稿和目标手机上验收。

视频号站展示入口排版与承接效果，播放原创本地 MP4 样片，没有连接实际视频号账号。真实视频号需使用公众号后台提供的插入入口。音频由点击触发；GIF 不含声音。网页下载在部分微信内置浏览器可能受限，生成海报后可长按图片或改用系统浏览器保存。

## 文件与复用

- `index.html` / `style.css` / `app.js`：可直接发布的页面。
- `assets/world.svg`：贯穿全篇的单张连续背景。
- `assets/native.json`：10 份原生 SVG 样例。
- `assets/tea-loop.gif`：3 秒循环；`town-film.mp4`：9 秒原创图形样片；`chime.wav`：原创合成风铃。
- `assets/filmstrip.webp`：60 帧图集；`puzzle.svg`：拼图素材。
- `scenes.json`：效果索引。
- `build.mjs`：执行 `node build.mjs`，重新生成 HTML、背景与索引。
- `create-media.py`：安装 Pillow、imageio-ffmpeg 后可重新生成原创媒体素材。运行演示无需 Python。

所有插画、图形动画与音频均为本演示用代码生成，不依赖外部素材地址。
