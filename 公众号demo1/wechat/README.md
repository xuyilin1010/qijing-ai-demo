# 公众号草稿测试版

打开 index.html，点击“复制正文（富文本）”，粘入公众号正文，保存草稿并发手机预览。

若图片缺失，先上传两张素材到公众号，填写微信图片 URL，再复制。默认 GitHub 图片仅供初测，不能视为公众号已接收图片。

保留：点击封面揭开、三个 Tab 切换、光圈、短笺开合、星空点亮与重置。
调整：三张手记提供点击圆点切换；正文末尾另附原生 HTML 上下滚动容器，用于测试滚动和吸附是否被保留。
不包含：网页脚本编辑器、滚动进度计算、随滚动移动的路线光点。路线为静态底图，不能把定时动画称为滚动跟随。

本包没有运行公众号后台操作，不保证普通粘贴保留 SVG。粘贴后若 SVG 变静态或消失，使用支持公众号 SVG 的排版器源码导入流程。不要把 HTML 代码作为文字粘贴正文。

验收顺序：粘贴后显示 → 保存重新打开 → 微信手机预览 → 点击展开 → 三个 Tab 依次切换 → 短笺开关 → 星空点亮重置 → 底部手记上下滚动。分别记录图片、动画、点击、滚动是否正常。
