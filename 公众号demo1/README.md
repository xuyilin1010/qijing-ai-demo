# 循光而行 · 可编辑旅行探索 Demo

双击 `index.html` 打开。图片、样式、代码均已内嵌，无需联网或安装依赖。点击“开启旅程”，滑动长卷或使用底部场景导航。竖屏时画面旋转，建议横握手机体验。

## 当前内容

独立、无品牌的旅行探索主题。蓝金色电影感景观连接海岸、沙丘、峡谷与星空。

| 位置 | 交互 | 实际素材与实现 |
| --- | --- | --- |
| 封面 | 进入长卷、横握提示 | PNG + HTML/CSS/JavaScript |
| 海岸 | 点击“循光出发”，光路展开 | PNG 底图 + SVG 路径动画 |
| 沙丘 | 点击短笺，打开与关闭文字卡片 | SVG set 控制显隐 |
| 峡谷 | 看山／看水／看天空，切换局部风景 | PNG + SVG set 控制图层 |
| 星空 | 点亮星座、重置 | PNG + SVG 路径与透明度动画 |

本版没有 GIF、MP4 或外部视频号内容。参考录屏只能确认可见交互与运动，不能确认局部影像的源文件究竟是 GIF、视频还是序列帧。

## 修改文字和图片

封面底部或长卷右下角点击“编辑”。文字实时生效，图片支持 PNG、JPEG、WebP、GIF（单张不超过 8 MB）。建议文字长度接近原文，以免超出版面；图片将保持原构图裁切。修改不会自动保存，离开前点击“下载修改后的页面”，获得可独立打开的完整 HTML。

也可编辑 `config.json` 的文字和 assets 路径，替换 assets 目录的文件后，在本目录执行 `node build.mjs`，重新生成三个交付文件。编辑器导出的配置也可覆盖 config.json 再构建，上传图片会以 data URL 保存在配置内。

## 文件

- index.html：完整浏览体验及编辑器。
- journey.svg：不含 JavaScript 的 SVG 长卷源文件，所有图片内嵌。
- native.html：禁止脚本的 SVG 机制检查页，需自行横向滚动并点击热点。
- config.json：集中管理文字、素材、部分动效时长和短笺热点位置。
- build.mjs、shell.html、style.css、app.js：可修改、重新构建的源码。
- assets：生成的原始 PNG 景观。

## 适用范围与验证状态

这是本地交互 Demo，不是已验证可直接发布的公众号排版包。完整 HTML 的编辑器、封面与导航依赖 JavaScript；SVG 内的点击显隐与路径动画使用声明式 SMIL。公众号导入可能改写或删除元素及内嵌图片，后续需要按实际编辑器处理图片托管、内容结构，并在微信 iOS/Android 预览中实测。

已进行 Node 语法与构建检查、SVG XML 解析、ID 唯一性、事件引用完整性、无脚本检查。浏览器策略拦截本地文件预览，因此尚未完成浏览器视觉检查、点按/滑动、下载重开及真机验收。请勿将静态代码检查理解为运行兼容性证明。

## 视觉素材来源

使用内置 image_gen 图像生成工具创作两张无文字、无商标的风景底图。方向：宽幅写实蓝调海岸连接琥珀色沙丘、岩石峡谷与蓝色河流；第二张为深蓝银河、远山与金色沙丘。人物剪影、路径、按钮、文字和星座均为可编辑 SVG 元素。
