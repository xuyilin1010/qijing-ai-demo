# 循光而行 · 可编辑旅行探索 Demo

通过发布后的网页打开 `index.html`。在线首页小于 40 KB，图片从 assets 独立加载并复用缓存；文字与按钮无需等待图片下载即可显示。点击“开启旅程”，直接滑动长卷：竖屏向上滑，横屏向左滑，均支持反向回看。不需要逐章点击，底部仅显示阅读进度。电脑支持滚轮和鼠标拖动。编辑器下载的完整页面会重新内嵌图片，支持离线打开。

## 当前内容

独立、无品牌的旅行探索主题。蓝金色电影感景观连接海岸、沙丘、峡谷与星空。

| 位置 | 交互 | 实际素材与实现 |
| --- | --- | --- |
| 封面 | 进入连续长卷 | PNG + HTML/CSS/JavaScript |
| 海岸 | 点击“循光出发”，光路展开 | PNG 底图 + SVG 路径动画 |
| 沙丘 | 点击短笺，打开与关闭文字卡片 | SVG set 控制显隐 |
| 峡谷 | 左侧三个纵向 Tab，切换右侧加大画面 | WebP + 显式点击状态 |
| 手记 | 按画面方向上下滑动，切换海风／沙丘／夜色三组图文 | WebP + Pointer Events；主线方向继续原生滚动 |
| 星空 | 点亮星座、显示“已点亮”、重置 | WebP + 显式可见状态 + CSS 动画 |

本版没有 GIF、MP4 或外部视频号内容。参考录屏只能确认可见交互与运动，不能确认局部影像的源文件究竟是 GIF、视频还是序列帧。

## 修改文字和图片

封面底部或长卷右下角点击“编辑”。文字实时生效，图片支持 PNG、JPEG、WebP、GIF（单张不超过 8 MB）。建议文字长度接近原文，以免超出版面；图片将保持原构图裁切。修改不会自动保存，离开前点击“下载修改后的页面”，获得可独立打开的完整 HTML。

也可编辑 `config.json` 的文字和 assets 路径，替换 assets 目录的文件后，在本目录执行 `node build.mjs`，重新生成三个交付文件。编辑器导出的配置也可覆盖 config.json 再构建，上传图片会以 data URL 保存在配置内。

## 文件

- index.html：完整浏览体验及编辑器。
- journey.svg：不含 JavaScript 的 SVG 长卷源文件，所有图片内嵌。
- native.html：禁止脚本的 SVG 机制检查页，需自行横向滚动并点击热点。
- config.json：集中管理文字、素材、部分动效时长和短笺热点位置。
- build.mjs、shell.html、style.css、mobile.css、app.js：可修改、重新构建的源码。
- assets：生成的原始 PNG 景观及在线使用的 WebP 压缩版本。在线只加载两张共 265,272 字节的 WebP，多个位置复用缓存。

## 适用范围与验证状态

这是独立网页交互 Demo，不是已验证可直接发布的公众号排版包。HTML 使用 JavaScript 管理点击状态与手记滑动，避免移动 WebView 的 SMIL 事件兼容差异。journey.svg/native.html 单独保留无脚本 SMIL 基础效果，但不具备 H5 的手势翻卡能力。公众号导入需单独适配，不能直接将 H5 代码粘入公众号正文。

已在已发布页面验证：844×390 横屏下纵向 Tab 切换，图文卡片正向第 1→2→3 张及反向切换，星空点亮／重置／再次点亮；390×844 竖屏下的对应拖动方向与原生长卷滚动另行检查。浏览器尺寸与鼠标拖动验证不等于微信真机触摸验收。尚未验证微信 iOS/Android 真机、公众号正文导入和修改页面下载重开。

## 视觉素材来源

使用内置 image_gen 图像生成工具创作两张无文字、无商标的风景底图。方向：宽幅写实蓝调海岸连接琥珀色沙丘、岩石峡谷与蓝色河流；第二张为深蓝银河、远山与金色沙丘。人物剪影、路径、按钮、文字和星座均为可编辑 SVG 元素。
