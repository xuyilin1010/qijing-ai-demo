## 4. 页面结构

入口为竖屏封面。点击封面任意位置后，进入横向连续长卷。手机竖屏环境下，长卷整体旋转 90°，用户保持竖屏握持并上下滑动，视觉上等价于横向浏览。

长卷共 8 个章节，每章宽度为一个横屏视口：

| 序号 | 章节 | 主要内容与交互 |
| --- | --- | --- |
| 0 | 探索序言 | 横屏观看提示、主标题、向右滑动提示 |
| 1 | 星空 | 16:9 视频占位 |
| 2 | 攀登 | 16:9 视频占位 |
| 3 | 奔跑 | 16:9 视频占位 |
| 4 | 感官／体验／情感 | 左侧三个 Tab；点击或键盘方向键切换右侧内容 |
| 5 | 三大先锋圈层 | 户外探索型、品质创新型、潮流先锋型；点击进入对应人物故事 |
| 6 | 人物故事 | 三个故事上下切换；支持按钮、图片区域手势和鼠标滚轮 |
| 7 | 结尾 | 独立蓝金地平线背景、宣言、公众号/视频号二维码占位、回到起点 |

## 5. 核心文件职责

### `index.html`

- 全部章节 HTML、文案、ARIA 属性、视频和二维码占位结构。
- `#entry` 是竖屏封面。
- `#experience` 是展开后的横向长卷。
- `#landscape-sources` 内四张图片只供前半段 Canvas 背景渲染使用。
- `.final-flow-art` 是第 5、6 章共用的两页连续背景层。
- `.closing-background` 是末页自己的独立背景，不与前两页共用。

### `base.css`

- 早期版本继承的基础样式，包含封面、视频占位、人物卡、故事、联系方式等通用规则。
- 文件较密集，修改前先搜索具体选择器，避免重复规则互相覆盖。

### `panorama.css`

- 当前长卷布局和绝大多数最终覆盖样式。
- `#surface` 与 `.rail` 均为 `calc(var(--pw) * 8)`。
- `.rotated` 负责手机竖屏时的 90° 旋转和纵向滚动映射。
- 后半段存在多轮追加覆盖，**最终有效规则以文件底部为准**。继续修改时建议先整理重复的 `.final-flow-art`、`.closing-background`、`.closing-contact` 规则，再做较大改版。
- 当前第 6 章到末页的过渡由 `.stories:after` 与 `.closing:before` 两个宽渐变完成；不要改成硬边黑条。

### `app.js`

- 计算横屏逻辑尺寸 `--pw`、`--ph`。
- 封面展开/返回封面。
- 横向滚动、桌面鼠标拖拽、方向键、手机旋转映射。
- Tab 状态：`setFeature(index)`，使用 `data-feature-tab` / `data-feature-panel`。
- 人物故事状态：`setStory(index)`，使用 `data-story-open` / `data-story-go` / `data-story`。
- 人物画像跳转故事页的位置是 `6 * 视口宽度`；章节增删后必须同步修改。

### `background.js`

- `PanoramaRenderer` 使用屏幕大小 Canvas 渲染前半段背景。
- 当前 Canvas 只组合 `cover.png`、`stars.png`、`climb.png`、`run.png`。
- 第 5、6、7 章使用普通 DOM/CSS 图片层，避免超长 Canvas 在部分手机浏览器中变黑。
