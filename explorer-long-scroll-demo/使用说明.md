# V4 · 探索主题横幅长卷

在线预览：https://xuyilin1010.github.io/qijing-ai-demo/explorer-long-scroll-demo/

这是用户确认继续制作的不含烟草品牌及产品宣传的通用探索主题版本。

## 阅读方式

点击封面任意位置展开。正文是一条连续横向画布，没有顶部导航、章节 Tab 或整屏翻页。

桌面可用鼠标横向拖动、滚轮或触控板连续移动；横持手机可左右拖动。竖持手机时整个画布旋转为横屏构图，通过正常上下滑动沿画布前进。浏览器不能替用户实际旋转设备，本版本采用 CSS 旋转呈现；左侧有转屏图标与提示。

首屏文字与光环向左调整；已移除「点击探索」按钮。「向右滑动探索」提示位于右下侧，循环淡入淡出。支持键盘方向键、Home/End，Esc 返回封面。文末也可返回封面。

人物照片可沿画面上下方向拖动切换，也可用旁边的箭头或序号选择。三个视频为独立 16:9 占位，尚未提供播放素材。联系方式也为占位。

## 画布与资源

四组已有原图保持原文件：光环 → 星空 → 攀登 → 奔跑。所有内容区域均为透明背景，风景统一采用长卷坐标，通过重叠渐变衔接；尾段延伸为克制的深蓝夜色。

针对用户反馈的手机背景消失，背景改为独立的屏幕尺寸 Canvas，只绘制当前可见范围，不再依赖超宽旋转 CSS 遮罩层。发布版使用 WebP：先加载竖版封面，再低优先级预取横卷第一张背景；其余三张进入长卷后才请求。加载完成及滚动时重绘；像素密度上限为 2，以控制手机内存占用。

这是网页中的完整横幅合成布局，并非把四张照片逐页作为独立背景。未将照片重新生成，也没有另行输出一张拼接位图。背景坐标与混合在 background.js 中调整；文案、排版、交互分别在 index.html、panorama.css、app.js 中调整。

手机尺寸浏览器验证：390×844，滑动至 844、1688、2532 像素时，星空、攀登、奔跑背景均可见，已保存截图。真实手机微信内的修复效果仍需在对应设备确认。

无外部依赖，可离线打开 index.html。独立 H5，不是可直接粘贴到微信公众号正文的原生无脚本 SVG。

2026-09-23 加载优化：原始 PNG 继续保留为设计源图，页面改用 `assets/*.webp`；三个相同的尾段源图共用 `assets/journey-flow.webp`。非当前人物故事照片在选择相应故事时加载。运行 `uv run --with pillow --no-project python -X utf8 optimize-images.py` 可从原 PNG 重建发布版素材。

V2、V3 的本地和源码归档仍保留。本版本位于独立的 v4-探索主题横幅长卷 目录，更新现有连续长卷在线入口。
