# 向未知前行 · V3 连续长卷

预览：https://xuyilin1010.github.io/qijing-ai-demo/explorer-long-scroll-demo/

原 V2 分页版保留：https://xuyilin1010.github.io/qijing-ai-demo/explorer-scroll-demo/

双击 index.html 也可以离线打开。图片、样式及脚本均使用相对路径，不依赖外部服务。

## 本版交互

- 竖屏封面选择观看方式，点击箭头后封面收起，整篇正文一次展开。
- 正文为浏览器原生连续滚动，内容顺序为文化核心、产品定位、产品介绍、场景视频、人物画像、人物故事、联系方式。
- 无全局章节 Tab、上一页/下一页、自动吸附或整屏翻页。可以停在任意两段之间。
- 手机上选择「横屏沉浸」：竖持时将内容旋转为横向构图，连续滑动阅读；选择「适应屏幕」：竖排阅读。桌面及横持设备采用横幅构图组成纵向长文。
- 星空、攀岩、奔跑按钮只切换视频所在区域，保留三个 16:9 占位。
- 人物区域可点上下箭头或序号切换，也可在人物照片上沿画面上下方向拖动。整篇滚动不被其他区域拦截；人物照片滚轮到首尾时仍可继续滚动正文。
- 文末「回到起点，再看一次」返回封面，重新打开时视频和人物恢复第一个。

## 验证范围

已验证桌面 1280×720、手机尺寸 390×844 和 844×390 的布局；封面展开、连续滚动停在段落之间、局部视频选择、人物按钮和图片拖动、到达文末、返回重置以及窗口尺寸切换。素材无加载缺失，未观察到浏览器脚本错误。

这是独立 H5 预览实现，包含 JavaScript。尚未验证微信公众号正文原生 SVG 发布或真实手机微信内浏览器，不能直接作为公众号无脚本正文粘贴。
